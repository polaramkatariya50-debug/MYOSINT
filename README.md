# OSINT Telegram Bot

Production-ready Telegram bot with:
- Must Join + Verify
- Credit system (2 credits per search)
- Referral rewards
- 9 OSINT APIs with **exact same formats**
- MongoDB backend
- GitHub-ready structure

## Setup
```bash
pip install -r requirements.txt
cp .env.example .env
# Fill .env values
python bot.py
```
